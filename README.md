# caellumkennedy.com

Personal CV / portfolio site for Caellum Kennedy — software engineer, Galway, Ireland.

Hand-built with semantic HTML, modern CSS and a small amount of vanilla JavaScript.
No frameworks, no build step. Hosted on GitHub Pages.

- Self-hosted Inter variable font, inline SVG icons (no external CDNs)
- Light/dark theme (system preference + manual toggle, persisted)
- Optimised WebP images generated from original photographs
- Photography: Leenane Hill and the Connemara mountains, by me

## Local development

Any static file server works, e.g.:

```
python -m http.server 8090
```
